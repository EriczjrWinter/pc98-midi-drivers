# 雫 -しずく-（LEAF, 1996・PC-98）

## 数据

| 文件 | 说明 |
|---|---|
| `mmdr.com` | MIDI 驱动（3218 B），作者 H.Ninomae |
| `mmdr_98.com` | 装载器（400 B） |
| `sz_gs00..24.md` | **MIDI 音源**曲数据，25 首 |
| `sz_fm00..24.fm` + `pmd.com` + `SZEF.EFC` | FM 音源版（标准 PMD） |

> **MIDI 版的驱动和 FM 版的驱动是两套东西。** FM 侧用的是通用的 PMD，
> MIDI 侧才是 LEAF 私有的 MMDR。

## 曲目表

曲名有两个来源，**它们是两张不同的专辑**：

| 专辑 | 年份 | 曲名风格 | 用在哪 |
|---|---|---|---|
| LFCD-0003「雫・痕 オリジナルサウンドトラック」 | 1996 | **场景名**（オープニング、授業中…） | 原始版 |
| LFCD-0012「雫 ORIGINAL SOUND TRACK」 | 2004（重制版附赠） | **正式曲名**（退屈、不穏、邂逅…） | 本仓库采用 |

所以当前命名是 **「重制版曲名(场景)」**，例如 `09 不穏(調査)`。

### GS15 / GS18 对调的依据

用 HOOT 录制的 5 份参考 MIDI 逐一对比，前 300 个音符：

- 名为「雫 -しずく -(オープニング)」的录音 → 与 `SZ_GS15` 完全一致
- 名为「月蝕(バッドエンド)」的录音 → 与 `SZ_GS18` 完全一致

所以是 **HOOT 的曲名表错了**，还是文件实际内容与名字错位，不影响导出的数据本身，
但**按名字取曲目时要注意**。

## 导出

```bash
python src/mmdr_emu.py --dir <雫的目录> --all --count 25
```

## 备注

- 循环曲目会自动截成一遍
- 每首的 tempo 不同（来自 `.MD` 头部的 8253 计数）：GS07 是 10.00 ms，GS16 是 13.02 ms
- 参考录音的时长是按 CD 版 WAV 决定的，与 PC-98 版的实际长度不一定相同
